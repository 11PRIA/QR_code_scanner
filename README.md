# QR Code Generator

A simple, elegant, and responsive QR code generator web application that allows users to convert any text or URL into a scannable QR code instantly.

## 🌐 Live Demo

**[Try it out here](https://qrcodescanner11.netlify.app/)**

## ✨ Features

- **Instant QR Code Generation**: Convert text or URLs to QR codes in real-time
- **Responsive Design**: Works seamlessly on desktop, tablet, and mobile devices
- **Clean & Modern UI**: Beautiful, user-friendly interface with smooth animations
- **Error Handling**: Visual feedback for invalid inputs
- **No Dependencies**: Pure HTML, CSS, and JavaScript implementation
- **Free API Integration**: Uses reliable QR code generation API

## 🚀 How to Use

1. **Enter Text or URL**: Type any text or URL in the input field
2. **Generate QR Code**: Click the "Generate QR code" button
3. **Download/Share**: The QR code will appear instantly and can be saved or shared

## 🛠️ Technologies Used

- **HTML5**: Semantic markup and structure
- **CSS3**: Modern styling with animations and responsive design
- **JavaScript**: Dynamic functionality and API integration
- **QR Server API**: External API for QR code generation
